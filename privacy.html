Personal Bug Book — Privacy Policy

Last updated 2026-09-12. This is a personal, single-user tool, not a public service.

What this app does

Personal Bug Book is a private self-observation log. It has no server, no analytics, no advertising, and no account system of its own.

What data it stores, and where

The only data it handles is what you type into the log yourself — dates, sleep hours, notes, and similar entries you write. That data is saved as a single JSON file in your own Google Drive account, the same file this app's desktop counterpart already writes to. It is never sent to any server other than Google's own Drive API, and never shared with any third party.

What access it requests

Sign-in uses Google's drive.file scope, which only grants access to the one file you explicitly pick via Google's file picker when you set the app up. It cannot see, list, or touch any other file in your Drive.

Your control over this data

You can revoke this app's access at any time from your Google Account's Security & permissions page. Removing that access, or deleting the file itself, removes the app's ability to read or write your data — nothing is retained anywhere else.
